## 갈래 보완
- [ ] 민재의 지하상가 10시간 · 맨손일 때, 늘 몸에 지니는 최소 키트
- [ ] 귀가길 40분 · 통제선, 잔해·불발탄, 전깃줄, 연기
- [ ] D-5 연락 규칙 카드에 "교대로 기다리기, 떠날 땐 쪽지" 미리 넣기
- [ ] 3차 약속(외삼촌 전화)을 대사 한 줄로 회수
- [ ] 두 번째 갈래 · 서진이 병원에 남는 경우 (전시 동원 문제와 함께)

## 내용상 빠진 상황
- [ ] 차를 버리고 걷는 상황 (계획에 도보 시간만 적혀 있고 장면은 없음)
- [ ] 전시 동원 문제 · 서진(응급실 간호사), 민재(20세 휴학생). 법적 기준 확인 후 반영
- [ ] 장기화 대비 · 한 달 치 혈압약 이후 처방, 식량·현금 소진

## 사실 확인
- [ ] 민방위 경보 체계 (경계 1분 평탄음, 공습 3분 파상음, 화생방은 방송·재난문자)

- [ ] 화생방 행동 요령을 국민재난안전포털 최신 기준과 대조
- [ ] 출처 링크와 확인 날짜를 페이지에 표기

## 후속편 후보
