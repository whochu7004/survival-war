# 생존 - 전쟁편 · 남쪽으로 가는 길

한반도에서 전쟁이 일어났다고 가정하고, 안양시 박달2동의 한 가족이 미리 계획을 세우고 대피하고 남쪽 피난지까지 가는 9일을 따라가는 대비 훈련용 애니메이션입니다.

## 브라우저에서 바로 보기

- **[▶ 애니메이션 보기](https://whochu7004.github.io/survival-war/)** · 「남쪽으로 가는 길」 (본편, 갈래, 복귀편, 선택형 모드)
- **[📝 우리 가족 계획서](https://whochu7004.github.io/survival-war/plan.html)** · 화면에서 채우고 인쇄할 수 있는 빈칸 양식

위 링크는 GitHub Pages 주소입니다. 저장소 Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정해 켜야 열립니다. 켠 뒤 1~2분 걸릴 수 있습니다. 내려받아 쓸 때는 `index.html`, `plan.html`을 브라우저로 직접 열어도 됩니다 (글꼴은 Google Fonts에서 불러옵니다).

`plan.html`은 **우리 가족 계획서**입니다. 이야기 속 카드를 빈칸 양식으로 옮긴 페이지로, 화면에서 채우거나(이 브라우저에만 저장) 브라우저 인쇄(Ctrl+P)로 A4에 출력할 수 있습니다. "빈 양식 보기"를 켜고 인쇄하면 빈 양식이 나옵니다. 애니메이션 아래 링크로도 들어갈 수 있습니다.

## 구성

- 본편 24장면 · D-7 준비부터 D+8 휴전 협상 소식까지
- 화생방경보 대응 장면 (D-Day 밤)
- 갈래 1 · 가족이 흩어졌을 때 (7장면). 밖에 있던 민재와 지하에서 기다리는 가족, 두 시점. 공습경보 장면에서 갈라져 그날 밤 화생방 장면으로 합류
- 갈래 2 · 서진이 병원에 남을 때 (3장면). D+1 출발 장면에서 갈라져 같은 장면으로 돌아옴
- 갈래 3 · 차를 두고 걸을 때 (4장면). 세이프 5에서 갈라져 피난지 생활 장면으로 합류
- 갈래 4 · 피난이 길어질 때 (10장면, D+100까지). 약, 식량, 현금, 생활, 겨울나기, 난로와 일산화탄소, 지원 신청과 일, 감기, 마을 회의, 100일 점검. D+8에서 갈라져 에필로그로 합류
- 복귀편 (7장면). 갈래 4(D+100)에 이어 귀가 허용 발표, 떠날 때 정리, 돌아가는 길, 서진과 다시 만나기(갈래 2를 본 분께), 집에 들어가기 전·후 점검, 다시 준비하기. 에필로그에서 들어가 에필로그로 돌아옴
- 장면마다 행동 카드, 경보 장면의 사이렌 소리 (켰을 때만)
- 선택형 모드 · "선택형" 버튼을 켜면 결정 장면 10곳에서 장면보다 먼저 질문이 나오고, 고른 뒤 이유와 함께 장면을 봅니다. 처음에 맞힌 수를 표시합니다

## 장면 고치기

장면 데이터는 `index.html` 안의 `S`(본편), `BR_APART`, `BR_HOSPITAL`, `BR_WALK`, `BR_LONG`(갈래), `BR_RETURN`(복귀편) 배열에 있습니다. 각 장면은 `when`, `title`, `narr`, `lines`, `card`, `draw` 로 이루어져 있습니다.
- `fork: {to, text}`: 이 장면에서 `to` 갈래로 들어가는 버튼을 보여 줍니다.
- `rejoin: '<갈래 id>'`: 그 갈래가 끝나면 이 장면으로 돌아옵니다. 없으면 갈라진 장면으로 돌아옵니다.
- 결정 장면의 질문은 `CHOICES`에 장면 제목을 키로 `{q, options: [{t, ok, why}]}` 형식으로 적습니다.
- 새 갈래는 `BRANCHES`에 `{scenes, end, btn}`으로 추가합니다. `label`(진행 표시 이름, 기본 '갈래')과 `open`(들어가는 버튼 이름)은 선택입니다.
