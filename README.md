# 생존 - 전쟁편 · 남쪽으로 가는 길

한반도에서 전쟁이 일어났다고 가정하고, 안양시 박달2동의 한 가족이 미리 계획을 세우고 대피하고 남쪽 피난지까지 가는 9일을 따라가는 대비 훈련용 애니메이션입니다.

`index.html` 하나로 동작합니다. 브라우저로 열면 됩니다 (글꼴은 Google Fonts에서 불러옵니다).

## 구성

- 본편 24장면 · D-7 준비부터 D+8 휴전 협상 소식까지
- 화생방경보 대응 장면 (D-Day 밤)
- 갈래 5장면 · 가족이 흩어졌을 때. 밖에 있던 민재와 지하에서 기다리는 가족, 두 시점 (공습경보 장면에서 갈라져 그날 밤 화생방 장면으로 합류)
- 장면마다 행동 카드, 경보 장면의 사이렌 소리 (켰을 때만)

## 장면 고치기

장면 데이터는 `index.html` 안의 `S`(본편)와 `BR`(갈래) 배열에 있습니다. 각 장면은 `when`, `title`, `narr`, `lines`, `card`, `draw` 로 이루어져 있습니다.
- `fork`: 이 장면에서 갈래로 들어가는 버튼을 보여 줍니다.
- `rejoin`: 갈래가 끝나면 이 장면으로 돌아옵니다.

## 주의

등장인물, 마을, 대피소 지정 여부, 도로 상황, 피난 목적지는 모두 꾸민 설정입니다. 실제 비상 상황에서는 정부·지자체·군의 공식 안내를 따르고, 가까운 대피소는 안전디딤돌 앱이나 국민재난안전포털에서 확인하세요.
